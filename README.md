# 👤 Cartão de Perfil

Um projeto simples de desenvolvimento web que apresenta um cartão de perfil pessoal, com nome, profissão e links para redes sociais.

O projeto foi desenvolvido como parte dos estudos de **Programação Web**, com foco na estruturação de páginas utilizando HTML e na estilização de elementos com CSS.

## 🚀 Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização dos elementos e personalização visual do cartão.

## ✨ Funcionalidades

- Exibição de avatar com iniciais do usuário.
- Apresentação do nome e da profissão.
- Links para redes sociais:
  - GitHub
  - LinkedIn
  - Instagram
- Botão de contato com o texto "Fale comigo!".

## 📂 Estrutura do projeto

```text
cartao-perfil/
├── index.html
└── style.css
```

## 💻 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd cartao-perfil
   ```

3. Abra o arquivo `index.html` em seu navegador.

## 🎯 Objetivo

Praticar os fundamentos do desenvolvimento web, aplicando conceitos de HTML semântico, organização de elementos e estilização com CSS.
